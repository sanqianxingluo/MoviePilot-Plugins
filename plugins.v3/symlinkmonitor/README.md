# 软链接监控（SymlinkMonitor）

MoviePilot **V3** 插件：**只监控，不建链**。盯着下载目录，发现文件被删除后延迟确认，
再把软链接目录（媒体库）里指向它的那个链接删掉，并联动清理刮削文件、转移记录、
下载种子与空目录。

## 功能

| 功能 | 说明 |
| --- | --- |
| 监控下载目录 | 每行一条 `下载目录:软链接目录`；只在这些目录里找变化 |
| **不建软链接** | 本插件**不会**创建任何软链接，链接由你自己的工具（MoviePilot 整理、hlink 等）负责 |
| 延迟删除 | 文件消失后不立即动手，等 `delay_seconds`（默认 30 秒）再确认真删除 |
| 删除软链接 | 源文件删除后，删掉软链接目录中指向它的链接（同名推导 + 按链接目标全扫，应对改名/分类目录） |
| 孤儿清理 | 「立即运行一次」扫描并清掉指向下载目录、但源文件已不存在的**断链** |
| 清理刮削文件 | 清理软链接目录里同名的 `.nfo/.xml/图片/字幕` 与 `.trickplay` 等刮削；下载目录侧默认不动 |
| 清理下载目录刮削 | 单独开关，默认**关**——下载目录（源数据）默认只读 |
| 删除转移记录 | `TransferHistoryOper.get_by_src()` 找到并删除对应整理记录 |
| 联动删除种子 | 用转移记录的 `download_hash` 触发 `DownloadFileDeleted`，移除下载任务（**不删数据**） |
| 清理空目录 | 自下而上清理，遇到下载目录根 / 软链接目录根 / 不删除目录即停 |
| 发送通知 | 每次联动清理发一条通知（可关） |
| 启用插件 | 顶部开关 |
| 立即运行一次 | 立刻全量清理一次孤儿断链，不等延迟 |
| 保护目录（不删除目录） | 每行一条；这些目录里的内容**仍会被监控**，但插件**绝不会删除**它们（含子目录） |
| 排除关键词 | 正则，命中完整路径则忽略该文件 |

## 双向行为

- **删下载目录里的文件** → 清理软链接目录里指向它的软链接（主功能）
- **删软链接目录里的链接** → **不会**影响下载目录

## 安全底线

- **只删软链接本身**，软链接目录里的真实文件一律不动（遇到同名真实文件会跳过并告警）。
- **下载目录默认只读**：本插件默认不删除下载目录里的任何文件（要清源侧刮削需显式打开开关）。
- **只删指向监控目录的链接**，指向别处的无关链接不碰。
- 「保护目录」里的链接不删；其中的文件照常监控。

## 配置项

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | 关 | 启用插件 |
| `notify` | 开 | 发送通知 |
| `onlyonce` | 关 | 立即运行一次（全量清理孤儿断链） |
| `monitor_dirs` | 空 | 监控目录，`下载目录:软链接目录` 每行一条 |
| `exclude_dirs` | 空 | 不删除目录，每行一条 |
| `exclude_keywords` | 空 | 排除关键词（正则），每行一条 |
| `scan_interval` | 10 | 扫描间隔（秒），最小 3 |
| `delayed_deletion` | 开 | 启用延迟删除 |
| `delay_seconds` | 30 | 延迟时间（秒），范围 5 ~ 86400 |
| `delete_scrap` | 开 | 清理软链接目录里的刮削 |
| `clean_source_scrap` | 关 | 是否也清理下载目录里的刮削（默认关，保护源数据） |
| `delete_history` | 开 | 删除转移记录 |
| `delete_torrents` | 开 | 联动删除种子 |
| `clean_empty_dir` | 开 | 清理空目录 |

## 安装

MoviePilot「设置 → 插件市场」中追加：

```
https://github.com/sanqianxingluo/MoviePilot-Plugins
```

或在 `config/app.env` 的 `PLUGIN_MARKET` 里追加该地址（逗号分隔）。

本地调试：`config/app.env` 加入 `PLUGIN_LOCAL_REPO_PATHS='/config/localrepo'`，
把本仓库放到 `<config>/localrepo/` 后重启容器即可。

## 测试

用例在 `tests/v3/symlinkmonitor/` 下，需在 **MoviePilot 容器内**运行（依赖 `app.*` 模块）：

- `test_symlinkmonitor.py` — 纯逻辑单测（配置解析、保护目录、排除规则、刮削匹配、链接目标解析等）
- `test_protect_dirs.py` — 保护目录语义（照常监控但绝不删除）
- `test_regress_config_guard.py` — 配置防呆（保护目录覆盖监控目录时忽略并告警）
- `test_deletion_log.py` — 删除记录（落盘、条数上限、计数与列表同源）
- `test_e2e_acceptance.py` — 端到端验收（启动无副作用、**新增文件不建链**、延迟删除、
  联动清理、真实文件保护、空目录清理、立即运行一次）

运行方式与约定见 `tests/README.md`。

> ⚠️ `test_e2e_acceptance.py` 会**临时改写插件的线上配置**（走 `PluginManager`），
> 用例已实现「先快照、结束还原」；**新增涉及配置的用例必须照做**，否则会把用户配好的
> 监控/保护目录冲掉。

## 注意

- **必须挂载**下载目录与软链接目录到容器内，且用**容器内路径**填写。
- 本插件删除的是**软链接**，因此链接必须真的是符号链接（`ln -s`）；
  若媒体库里是硬链接或真实文件，本插件不会删除它们。
- 联动删除种子**只移除下载任务，不删除已下载的数据文件**；数据文件由本插件按
  源文件删除事件处理。

## 安全边界（v2.1.1）

- **下载目录只读**：默认不删下载目录里的任何文件（含刮削）。要连源侧刮削一起清才打开「清理下载目录刮削」。
- **保护目录**：填进去的目录内容照常监控、照常触发联动清理，但插件绝不删其中任何东西（链接、刮削、目录都不动）。
- **只删软链接**：遇到同名真实文件一定跳过并告警。
- **只处理指向监控目录的链接**，别的链接不碰。

## 删除记录（详情页可视化，v2.2.0+）

插件每次执行清理都会记一条，**详情页可看到删了什么**（默认展示最近 20 条）：

- 时间、类型（源文件删除 / 孤儿清理）
- 源文件路径
- 删除的软链接数与具体链接路径
- 清理的刮削条目数与空目录数
- 是否联动了转移记录 / 下载种子

记录存在插件数据目录的 `deletion_log.jsonl`（追加写），最多保留 200 条，跨重启不丢。

接口：

```
GET /api/v1/plugin/SymlinkMonitor/deletions?limit=20   # 取记录
GET /api/v1/plugin/SymlinkMonitor/clear_log            # 清空记录
```
