# 115自动上传

监听 MoviePilot 的整理完成事件，把新入库的影视文件自动上传到 115 网盘。上传前会校验 115 上是否已存在同名影片或对应文件，重复时不上传并发送提示。

## 功能

- 监听 `transfer.complete` 事件，整理成功后自动处理目标影片/剧集目录。
- 按配置的路径映射，把本地媒体库路径转换为 115 目录结构。
- 默认连同 `nfo`、`poster`、`fanart` 等附属文件一起上传。
- 上传前查重：
  - 整部影片或整季已存在同版本视频：不上传，记录并通知。
  - 只缺部分集数：仅补传缺失文件，已存在的集不再上传。
  - 电影同名但文件大小不同：按已有影片处理，不上传并提示版本不同。
- 同一事件重复触发会去重，避免重复排队。
- 上传结果写入插件数据，可在插件详情页查看最近一次结果。

## 依赖

- MoviePilot V3（`system_version >= 3.2.0`）。
- 运行环境需可导入 `p115client`，通常由 `P115Disk` 插件安装；未安装时本插件无法上传。
- 需要一个有效的 115 Cookie。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 发送通知 | 上传完成、重复跳过、失败时通过 MoviePilot 通知渠道发送消息 |
| 上传前查重 | 关闭后只按文件级同名同大小跳过，不再整目录判定重复 |
| 上传附属文件 | 关闭后只上传视频文件 |
| 115 Cookie | 留空时读取 `/config/temp/115_cookie.json`（扫码登录脚本生成的登录态） |
| 路径映射 | 每行一条 `本地前缀 => 115 前缀`，前缀越具体越优先 |
| 上传并发数 | 默认 1，建议保持 1 以避免触发 115 风控 |

默认路径映射：

```text
/Movies1st/Link1/ => /媒体库/电影/
/Movies3rd/Link3/ => /媒体库/电影/
/TVseries2nd/Link2/ => /媒体库/电视剧/
```

## 说明

- 只读取本地文件，不修改、不移动源文件。
- 115 侧目录按“影片/剧集目录”组织，与本地媒体库结构一致。
- 本插件只负责把文件放进 115；若需要在媒体服务器中播放 115 内容，仍需配合 STRM 方案（如 `P115StrmHelper`）。
- 通知依赖 MoviePilot 已配置的消息渠道；未配置时结果仍会记录在插件日志与详情页。
